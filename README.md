# Lotto Lab v2

기존 `stjings/lotto`의 정적 호스팅·당첨 데이터 형식을 유지한 모바일 로또 분석 MVP입니다. 작업 브랜치는 `feat/lotto-lab-v2`이며 운영 배포는 수행하지 않았습니다.

## 실행과 검증

Node.js 20.19+ 또는 22.12+가 필요합니다 (개발 검증: Node 24).

```sh
npm ci
npm run dev
```

개발 화면: `http://localhost:5173/lotto/`

```sh
npm test
npm run build
npm run preview
npm run test:e2e
```

빌드 미리보기: `http://localhost:4173/lotto/`. E2E는 시스템 Chromium을 사용합니다. 다른 환경에서는 `CHROMIUM_PATH`로 실행 경로를 지정하거나 `npx playwright install chromium`을 실행하세요. E2E 전에는 빌드가 필요합니다.

`index.html`과 `src/`, `data/`는 별도 빌드 없이 정적 HTTP 서버에서도 동작합니다. Vite는 번들·검증용이며 런타임 프레임워크 의존성은 없습니다. `file://`에서는 모듈·Worker·데이터 로딩을 지원하지 않습니다.

## 구현 기능

- 모바일 하단 내비게이션, 라이트·다크 모드, 1~45 색상 번호 버튼
- 전체 당첨 기록 조회, 최근 1~10회 분석, 번호 빈도·3/5/10회·최근 출현 정보
- 제외수 0~39개, 회차 일괄 선택, 통계 추천 미리보기·부분 채택·선택 출처 표시
- 모든 필터 개별 활성화, 범위 슬라이더와 숫자 입력, 홀짝 복수 선택
- Worker 기반 100~100,000개 중복 없는 후보, 시드 재현, 진행률·취소·용량 안내
- 가중치 100점 정규화, TOP 5~50, 점수·랜덤·혼합 선정, 후보 간 최대 중복도
- 통과 후보 랜덤 비교 및 **필터·제외수를 적용하지 않은 1~45 완전 랜덤 비교군**
- 설정 프리셋·JSON 가져오기/내보내기, TOP 실험 기록, 구매 후보와 회차별 결과 비교
- 전체 통과 후보 CSV (현재 실행), 최근 10개 실험 TOP 저장, 설정 최대 30개

## 데이터와 운영 보존

`data/all.json` → `data/recent.json`과 마지막 정상 캐시 중 최신 회차를 사용합니다. 모든 입력 데이터는 번호·보너스·회차·날짜를 검증합니다. 두 파일과 캐시가 모두 유효하지 않으면 오류를 표시하며 임의 데이터를 만들지 않습니다. 출처·최신 보유 회차·파일 갱신 시각(서버 제공 시)·확인 시각·갱신 지연을 구분합니다.

기존 `.github/workflows/update-lotto.yml`는 **변경하지 않았습니다**. 매주 토요일 15:30 UTC (일요일 00:30 KST), 기존 공개 데이터셋에서 `data/all.json`을 받아 커밋하는 흐름을 유지합니다. `data/recent.json`은 자동 갱신 대상이 아니므로 더 오래될 수 있습니다.

기존 README에서 안내한 GitHub Pages 설정은 main 브랜치 루트입니다. 이 작업은 그 설정과 배포를 변경하지 않습니다. `/lotto/` base와 상대 경로 Worker·데이터 로딩을 검증했습니다. 별도의 배포 workflow를 추가하지 않았고 main 병합·원격 push·PR 생성·공개 배포도 하지 않았습니다. 배포가 승인될 때 기존 main 루트 정적 파일을 사용할 수 있으며, `dist/` 산출물을 사용할지는 별도로 결정할 수 있습니다.

## 범위와 설계

통계 추천은 빈도·최근성 또는 미출현 기간의 휴리스틱이며 AI API를 사용하지 않습니다. 점수는 사용자 선호 조건의 적합도이고 당첨 가능성을 높인다는 뜻이 아닙니다. 완전 랜덤 비교군에는 제외한 번호가 포함될 수 있습니다.

백테스트는 `src/backtest.js`의 과거 데이터 격리·추천·당첨 평가 인터페이스와 테스트까지 구현했습니다. 회차 선택 실행 UI, 여러 회차 성과 집계, 사후 조건부 실험 화면, 생성형 AI 서버, IndexedDB·계정 동기화는 미구현입니다. 결과 저장은 localStorage를 사용하며 전체 100,000개 객체는 저장하지 않습니다. 전체 후보는 CSV로 내보내세요.

상세 분석, 변경 파일, 수학적 정의와 확인 결과는 [docs/REVIEW.md](docs/REVIEW.md)를 참고하세요.

## 화면 개선

따뜻한 밝은 번호 실험실 스타일로 분석·제외수·필터·실험·결과 화면을 분리했습니다. 데스크톱은 단계 내비게이션과 설정 요약, 모바일은 하단 이동과 단계별 컨트롤을 제공합니다. 최근 10회 빈도 히트맵에서 제외수를 고를 수 있고, 설정·저장 데이터는 기존과 호환됩니다. 최신 브라우저 테스트는 5개입니다.
